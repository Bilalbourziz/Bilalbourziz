# github-profile

A minimal static project that shows a profile-style page and includes an `assets/dark.svg` asset.

How to use
1. Open `index.html` in your browser, or serve the folder locally:
   - Python 3: `python -m http.server 8000` then visit `http://localhost:8000`
2. Replace `assets/dark.svg` with your own artwork if desired.
3. To publish on GitHub Pages:
   - Create a repository named `github-profile` (or any name).
   - Push these files to the repository and enable GitHub Pages from the repository settings (select branch `main` or `gh-pages`).

Contents
- `index.html` — the page that loads the SVG and shows basic profile info.
- `styles.css` — small stylesheet to center content and style the page.
- `assets/dark.svg` — placeholder SVG asset included in the project.
